# MVP 기술·제품 결정 (2026-10-19)

- 작업자 약 20명, 아르바이트 인력이 주 사용자
- 작업자 화면: 모바일 중심, 관리자 화면: 데스크톱 중심
- 작업 대상: 최초 엑셀 약 2,000건 (주소 포함)
- 지도: NAVER Maps SDK, 서버에서 주소를 좌표로 1회 변환/캐싱
- 사진: 건당 필수 4장, Cloudflare R2 비공개 버킷/접두사에 분리
- frontend: Vite + React + TS, Vercel (상업 이용 요금제 확인)
- backend: Spring Boot 모놀리스, 호스팅 미정
- DB: PostgreSQL + Flyway
- 계정: 관리자 발급, 일반 가입 없음. 활성화/비활성화 및 비밀번호 초기화 필요
- 작업 이력: 완료/수정/삭제는 사용자·시간 포함 감사 로그 작성
- 정산: 월별/전체, 완료시점 단가 스냅샷, 작업 내역 수정보다 독립적

## 잠정적인 업무 규칙
- 최초 엑셀의 고유키 존재 여부를 확인한다. 중복 업로드는 별도 정책 필요.
- 등록 단계에 실패한 주소는 수동 좌표 보정 대상으로 표시한다.
- 동시 수정은 version 기반 충돌 감지. 이력에는 수정 전/후를 포함한다.
- 삭제는 기본적으로 논리 삭제를 권장. 실제 삭제/정산 취소 규칙은 확인 후 결정.
- 정산 대상은 '완료'인지 '관리자 검수 완료'인지 발주자에게 확인해야 한다.
- 한글 출력은 양식/샘플 확인 후 별도 POC로 구현 방식을 확정한다.
- 인증/권한 구현 전에는 지도와 관리자 데이터를 반환하지 않는다.

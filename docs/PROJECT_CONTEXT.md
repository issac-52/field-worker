# 프로젝트 맥락

사람과 AI 에이전트가 작업 전에 읽는 현재 상태 요약입니다. 구현 여부는 항상 실제 코드와 테스트가 우선입니다. 결정의 근거와 검증 이력은 [주요 의사결정·해결 기록](DECISIONS_AND_PORTFOLIO.md)에 있습니다.

## 서비스

- 상수도 검침 현장 업무. 대상 수용가 약 2만 건, 실서비스 운영 중, 지역별 배포, 사용자 약 30명.
- 사무실(관리자): Excel 등록, 좌표 변환, 진행 확인, 정산, Excel·HWPX 출력.
- 현장(작업자): 휴대폰으로 대상 검색·지도 조회, START/END 검침, 사진 촬영.
- START는 2026년, END는 약 1년 뒤인 2027년에 진행하는 별도 검침입니다. 사용량은 END − START로 조회·출력 시 계산합니다.

## 업무 규칙

**계정과 권한**
- 공개 가입 없이 관리자가 계정을 발급합니다. 역할은 ADMIN / WORKER입니다.
- 첫 로그인 때 비밀번호 변경을 강제하고, 비활성화·초기화 시 기존 세션을 끊습니다.
- 작업자는 본인 실적만 보고 금액·정산 상태는 받지 않습니다. 권한과 CSRF는 서버에서 검사합니다.

**수용가 등록 (Excel)**
- 최종(FINAL) 양식과 이전(LEGACY) 양식을 선택합니다. 기본은 신규 등록 + 기존 기본정보 업데이트입니다.
- 수용가번호는 문자열로 보존하고 중복을 허용하지 않습니다. 파일 안 중복은 먼저 나온 행을 남기고 보고합니다.
- 번호가 없으면 주소와 이름으로 식별합니다.
- 업데이트는 비어 있지 않은 기본정보만 반영하며 빈 값으로 기존 값을 지우지 않습니다. 사진·특이사항·검침·확정 정산은 보존합니다.
- 좌표 변환에 쓰는 주소가 바뀌면 좌표를 비우고 변경 이력을 남겨 재변환 대상으로 만듭니다.
- 파일에 없는 수용가 삭제는 미리보기와 확인 문구 입력 후 실행하며, 확정·지급 정산이 있으면 막습니다.

**좌표와 지도**
- NAVER 주소 변환은 관리자만 실행하며 최대 100건을 10개 동시 호출로 처리합니다. 한 건 실패는 기록하고 계속 진행합니다.
- 재시도는 연결 계층 502·503·504에만 최대 두 번 합니다. 권한·할당량 오류는 즉시 중단합니다.
- 지도 마커는 목록과 독립적인 화면 범위 조회입니다. 확대 시 개별 마커(최대 500건), 축소 시 구역별 집계를 보여줍니다.

**검침과 사진**
- START와 END의 날짜·지침·작업자는 따로 관리합니다. END 지침이 START보다 작으면 저장하지 않습니다.
- 이미 등록된 단계는 409로 거절하고, 다른 사람이 먼저 수정한 검침은 버전 검사로 막습니다.
- 정산되지 않은 검침은 단건 초기화할 수 있으며 이력을 남깁니다.
- 시작검침완료는 START 기록과 원경·시작 근경 사진이 모두 있을 때만 표시합니다.
- 사진은 비공개 R2에 저장하고, DB에는 참조만 둡니다. 삭제는 대기열을 거쳐 실패 시 재시도합니다.

**정산과 출력**
- 정산은 묶음으로 처리하며 미리보기 토큰을 확정·지급 동작에 묶습니다. 확정·지급된 정산은 수정할 수 없습니다.
- HWPX 검침카드는 요청 시 백그라운드에서 생성하고 내용 해시로 캐시합니다. 날짜·단계별, 소블록 합본, 전체 ZIP 다운로드를 지원하며, 원본이 바뀐 결과는 다운로드를 막습니다.

**현장 연결 끊김**
- 최근 조회한 수용가 30개를 기기에 보존하고, 신규 검침·사진은 기기에 먼저 저장한 뒤 서버 전송을 확인하고 지웁니다.
- 대기 항목은 계정별로 분리하고, 응답이 유실된 요청은 서버 기록·사진과 대조해 중복 없이 처리합니다.

## 기술과 구성

| 영역 | 기술 |
| --- | --- |
| Frontend | React, Vite, TypeScript, TanStack Query, shadcn/ui, Tailwind v4, PWA. 시연 모드에서만 MSW 사용 |
| Hosting | Cloudflare Workers (정적 자산 + `/api` 프록시) |
| Backend | Java 21, Spring Boot 3.5, Spring Security(세션·CSRF), JPA, Flyway |
| DB | PostgreSQL 17, EC2 Docker Compose |
| Files | 비공개 Cloudflare R2 |
| 배포 | GitHub Actions → S3 아티팩트 → OIDC·SSM으로 EC2 반영 |

백엔드 패키지: `auth`, `user`, `worksite`, `excel`, `geocoding`, `inspection`, `photo`, `settlement`, `document`, `global`.

## 작업할 때

- Flyway 마이그레이션은 이미 적용된 파일을 수정하지 않고 새 버전을 추가합니다.
- 운영 DB, AWS, R2, 배포 설정 변경은 개발자 승인 후 진행합니다.
- 실제 고객 Excel·사진·인증정보는 저장소에 넣지 않고, 테스트에는 가상 데이터만 사용합니다.
- 지난 설계·인계 문서는 [docs/archive](archive/README.md)에 있으며 현재 상태를 뜻하지 않습니다.

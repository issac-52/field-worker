# ADR — 연간 검침과 시연용 모바일 UI 통합 (2026-10-22)

- **상태:** 요구사항 확정 / 프론트 구현 시안(실기기·빌드 검증 필요)
- **대상 저장소:** `issac-52/field-worker`, 기존 `frontend/`에 통합; `backend/` 보존.
- **연간 조사:** 수용가 마스터 정보를 엑셀에서 등록하고 작업자는 읽기만 한다. 봉인여부 기본값은 '봉인'. 매년 시작·종료 검침을 구분해 검침일자·계량지침·작업자 정보를 관리한다.
- **작업비:** 시작·종료단계는 담당 작업자와 건당 단가가 각각 다르다. 관리자는 단계 및 검침일자 구간을 지정해 기존 작업비를 일괄 조정할 수 있다. 향후 서버에서 감사 로그, 정산 마감 정책, 적용 금액 스냅샷을 도입해야 한다.
- **현장 입력:** 특이사항·사진 4장. 수용가명·급수전번호·계량기번호·급수구역 등 기초정보는 읽기 전용.
- **문서:** `경산시 - 소블록 - 관리번호` 명명 기준의 HWP 일괄 출력 예정. 아직 생성 API 미구현.
- **시연:** 모바일 우선 React SPA, MSW로 `/api` 응답을 모킹. 실데이터·실인증·실지도·R2·HWP 없음.
- **트레이드오프:** 납기를 위해 mock UI를 먼저 제공하되, 인증과 변경 감사 이력 없이 실제 현장 운영에는 사용하지 않는다.

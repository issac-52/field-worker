# 전체 지도 범위 조회 — 후속 제안

업데이트: 2026-10-23. **제안 / 백엔드·Mock 미구현.** 현재는 수용가 목록과 같은 검색·블록·전체 진행 상태 필터, 현재 페이지 최대 20개 마커를 사용한다. 지도 이동으로 주변 수용가를 자동 검색하지 않는다.

## 필요해질 때 검토할 계약

GET /api/site-map?west=...&south=...&east=...&north=...&zoom=...&middleBlockId=...&smallBlockId=...&q=...&status=...

- status는 TODO/IN_PROGRESS/DONE. 금액·사진 본문은 제외하고 서버 인증 범위를 적용한다.
- 좌표의 유한값·범위·영역 크기·zoom을 검증한다. 전세계 범위로 전체 조회를 우회하지 못하게 한다.
- 응답 후보: mode(markers|clusters), items, matchedCount, returnedCount, truncated, invalidCoordinateCount, bounds, zoom.
- 개별 마커는 ID/관리번호/이름/주소/좌표/전체 상태, 클러스터는 중심/건수/포함 영역을 반환한다. 선택하면 단건을 조회하거나 영역 확대한다.
- idle 후 debounce, 이전 요청 취소, query key에 bounds/zoom/필터 포함, 이전 응답의 최신 화면 덮어쓰기 방지가 필요하다.
- 1만 건을 전부 브라우저로 내려받지 않는다. 응답 상한·확대별 집계 기준은 실제 밀집도/서버 측정 후 정한다. 잘린 결과를 전체 결과처럼 표시하지 않는다.

## 선택의 기준

| 대안 | 장점 | 비용/제약 |
| --- | --- | --- |
| 현재 페이지 유지 | 단순하고 목록과 일치 | 지도 전체 탐색 제한 |
| bounds 개별 마커 | 필요한 영역만 조회 | 밀집 지역 상한/확대 안내 필요 |
| bounds + 서버 집계 | 대량 탐색에 유리 | 집계 쿼리·캐시·zoom 정책 필요 |

현재 페이지 방식을 유지한다. 후속 구현 시 같은 주소 여러 계량기, 잘못된 좌표/빈 영역, 빠른 이동의 응답 역전, 권한과 수량 제한을 검증한다. 지오코딩/좌표 보정 API도 아직 구현하지 않았다.
